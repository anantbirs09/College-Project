# College Projects Portfolio

Welcome to my project repository! This workspace contains a collection of my recent programming and web development work, showcasing a mix of object-oriented Java programming and responsive frontend design.

## 🚀 Projects Included

### 1. Java Pong Game
A classic, fully functional arcade-style Pong game built entirely in Java for a college project.
* **Technologies Used:** Java, Java GUI (Swing/AWT), Multithreading.
* **Features:**
  * Smooth paddle movement and ball collision physics.
  * Game loop handled via multithreading for consistent, lag-free performance.
  * Custom interactive graphical user interface.
* **How to Run:** Compile and execute the main Java class from your terminal or preferred Java IDE.

### 2. Ketuveda - Astrology & Spiritual Guidance Website
A fully responsive, multi-page frontend website designed to provide an online presence for a professional astrology and spiritual guidance practice.
* **Technologies Used:** HTML5, CSS3.
* **Features:**
  * **Custom Ambient Animations:** Features continuous background animations (`starPulse`, `sparkleShift`, and `wheelRotate`) to simulate a living night sky using pure CSS.
  * **Responsive Layout Architecture:** Built with fluid CSS grids and media queries to ensure the UI scales perfectly across desktop and mobile devices.
  * **Glassmorphism UI:** Utilizes backdrop filters and semi-transparent borders to create sleek, modern content panels.
* **Collaborators:** Developed in collaboration with Tanmay.
* **How to Run:** Navigate to the web project folder and double-click `index.html` to open it directly in any web browser.
